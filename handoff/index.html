目标一句话目标

把现有「小红书单人工作台」升级为「面向分支机构的多平台内容生产中枢」：员工在 小红书 / 抖音 / 视频号 多平台创作，经 合规审核 后 半自动发布，总部统一管理内容、账号、合规与 客户业绩。

发布方式：半自动（系统管创作 + 审核 + 存档 + 数据回流，员工手动发到各平台）。

APPS应用结构

轻流一个「应用」= 一个业务域。建议 3 个业务应用 + 1 个平台级 RBAC 配置（先于应用完成）。

前置顺序：组织与权限（RBAC）是合规审核流的前置依赖，必须先配置完成，再搭建 App-01/02/03。

流程轻流流程节点（内容审核流）

#节点类型负责人动作
1发起填写节点一线员工填写内容创作单 → 提交
2合规初审审批节点合规审核员通过 / 驳回（填原因）
3合规复审审批节点（可选）合规审核员(上级)仅「初审+复审」模式启用
4抄送抄送节点分支负责人 + 总部内容中台知会，不审批
5结束结束节点—通过后内容状态置「可发布」
硬卡点：内容不经人工审核无法进入「可发布」，无绕过入口；驳回后修改重提、原版本留痕。

规则隔离与安全

  • 越权访问返回 403（无数据泄露）。
  • 分支间数据完全隔离。
  • 离职员工账号即时停用，历史数据保留。

DoD验收标准

验收口径：可验证，研发以「测试能通过」为准。未定项标注「待业务确认」。

1内容创作 NEW

  • 8 类内容均能生成结构完整脚本。
  • 生成结果自动嵌入免责声明 + 执业编号（不可手动删除）。
  • 提交后内容「草稿 → 待审核」，进入审核队列。
  • 审核通过后可发布；发布后回填（平台/链接/时间），数据回流数据分析。
  • 早盘/尾盘收评数据段对接行情接口自动填充，观点段人工撰写。

2合规审核 NEW · 核心

  • 内容不经人工审核无法进入「可发布」（硬卡点）。
  • 敏感词自动扫描：违禁词硬拦截、风险词提醒。
  • 驳回可修改重提，原版本留痕。
  • 审核记录可导出，留存 ≥ 3 年（待合规确认）。
  • 支持单审 或 初审+复审（待确认）。

3组织与权限 NEW

  • 五类角色：系统管理员 / 总部内容中台 / 合规审核员 / 分支负责人 / 一线员工。
  • 越权访问返回 403。
  • 分支间数据完全隔离。
  • 离职员工即时停用、历史数据保留。

4客户业绩 NEW · 空框架

  • 支持「员工 × 平台 × 客户」三维查询。
  • 数据刷新频率 ≤ T+1（待确认）。
  • 权限：一线看自己、分支看本分支、总部看全局。
  • 业绩口径（开户/入金/交易/资产配置折算）固化（待业务确认）。

5模板中心 NEW

  • 总部可在线增/改/停模板。
  • 分支只能使用、不能改总部模板。
  • 模板变更保留版本记录。

6多平台泛化 8 个保留模块通用

  • 热点/选题/爆款/对标/拆解/账号矩阵等数据支持「平台」维度筛选。
  • 69 对标、177 账号矩阵、33 热点等真实数据无丢失迁移。
