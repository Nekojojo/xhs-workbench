# 小红书工作台 V2.3 - 方正证券

## 简介
方正证券新媒体内容运营工作台，服务于证券公司分支机构的小红书内容创作。

## 使用方式
直接在浏览器中打开 index.html 即可使用，或访问 GitHub Pages 部署链接。

## 每日更新
每日数据存储在 `data.js` 文件中，每天自动更新。更新数据只需替换此文件。

## 技术架构
- 纯前端单文件架构（HTML + CSS + JavaScript）
- 数据与框架分离：index.html（框架代码）+ data.js（每日数据）
- 支持 Chart.js 图表和 SheetJS Excel 导出
